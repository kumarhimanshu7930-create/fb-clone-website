# Facebook Clone

This project is a functional frontend clone of the Facebook social media platform, built to replicate its core UI/UX features.

## Features
- Responsive design across various screen sizes.
- Replicated Facebook interface including the navigation bar, feed, and sidebars.
- Implementation of modern CSS techniques for layout and styling.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Getting Started
To view this project locally:
1. Clone the repository.
2. Open `index.html` in your preferred web browser.
